# Eturn Telegram bot

Доступен по адресам t.me/eturn_bot или @eturn_bot

## Реализация

Упрощенная версия приложения Eturn, в которой намного меньше параметров настройки очередей и ее хода.

Из возможностей можно:
- Создать очередь
- Подать заявку в очередь и встать в нее
- Отслеживать свою позицию и первого участника
- Смотреть текущие очереди

Из урезанного контента:
- Очередь создается на месяц
- Вставать в очередь можно с автоматической частотой
- Таймер удаления позиции составляет одну минуту
- Нельзя посмотреть список участников и список позиций

Особенности:
- Можно будет пользоваться уведомлениями
